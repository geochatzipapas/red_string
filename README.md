Red String

A desktop detective game built with Python and PySide6. Drag evidence cards across a corkboard, link contradictions with red string, interrogate suspects (at a time penalty) and accuse the culprit before the clock runs out.

Four themed games, five linked cases each:

Cyber Crime Unit: data leaks, invoice fraud, ransomware, fake shops
Police Files: robbery, hit-and-run, arson, kidnapping
The Consulting Detective: Victorian locked-room and train mysteries
Inspector Blandé: comedic heists

Solve cases 1 to 4 to collect the codewords that unlock the final case. Greek language. Windows and macOS (build with PyInstaller).
